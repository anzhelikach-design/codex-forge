# Lesson 03 — HTML + CSS + Tailwind

Two Figma designs rebuilt as static pages. Both are standalone — open `index.html`
in a browser, no build step.

| Folder | What it is | Source |
|---|---|---|
| [`cliquezjustice/`](cliquezjustice/) | Responsive homepage — header, hero with search, category cards | Figma web design |
| [`blaze/`](blaze/) | Mobile app onboarding screen, fixed 393×853 | Figma mobile design |

## Notes

Both pages map Figma variables onto CSS variables, keeping the design-system names,
so `blue/brand/blue-90` in Figma is `blue-90` in the markup.

Commercial fonts were substituted with the closest free equivalents:
Miranda Sans → Figtree, Forma DJR Text → Inter.
